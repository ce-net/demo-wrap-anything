Demos / Wrap anything

Any program, a mesh service.

One command turns ImageMagick, pandoc or jq into a cell on the network. Any device can call it. Only the flags on its allowlist reach the program, with limits on size, time and memory. It gives back the same stdout, stderr and exit code you would get running it yourself, plus the hash of the exact program that ran.

Check a result yourself

Every answer carries the argv that ran and the sha256 of the program file. Run the same argv on the same program version and compare.

mkdir w && cd w && cp ~/your-image.png in.png
convert png:in.png -resize 50% -strip out.png
sha256sum out.png                      # = output_cid
sha256sum "$(readlink -f "$(command -v convert)")"   # = artifact_sha256 (same build)
